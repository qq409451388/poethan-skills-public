# Poethan Sentinel Plugins

这里存放随项目维护、但不打包进 macOS App 的诊断插件。

安装方式：

1. 在 Poethan Sentinel 的“设置 → 插件目录”中选择本目录；或
2. 在“管理检查脚本 → 新增 → 导入插件包”中选择某个插件目录，App 会将它复制到当前插件目录的 `<id>/<version>` 下；或
3. 手动把插件目录复制到设置中显示的插件目录，再点击“重新扫描”。

每个插件的根目录必须包含 `plugin.yaml`。App 会从该文件读取名称、版本、入口、运行模式、配置表单、输出限制以及报告 Schema/HTML 模板；校验失败的目录仍会显示在管理页，并附带具体原因。
