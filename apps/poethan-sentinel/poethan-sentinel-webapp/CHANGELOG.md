# Changelog

## 0.1.0-beta.1 — 2026-08-29

- 完成 React + TypeScript 本地 Web 客户端和 FastAPI Controller。
- 支持服务器增删改、SSH 别名/密钥/密码、主机指纹确认与连接测试。
- 支持 plugin.yaml 动态表单、目录导入、失败原因展示、开发者模式和 Ed25519 签名校验。
- 支持远端插件内容寻址缓存、临时配置、结果文件下载、停止和 15 分钟超时。
- 支持 SSE 执行进度、确定性结论、原始输出、历史报告、Schema 和插件 HTML 模板。
- 支持 OpenAI 兼容 AI 接口、DeepSeek 配置、连接测试和异步增强分析。
- 提供不依赖真实服务器和 API Key 的完整演示模式。
